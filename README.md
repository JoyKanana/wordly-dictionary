# wordly-dictionary
A single-page dictionary application built with HTML, CSS, and JavaScript
## Overview

## Features
 - search for English words.
 - View definitions and parts of speech.
 - Display pronounciation and examples when available.
 - View synonyms when available.
 - Show messages for empty searches or words that cannot be found.
 - Save favorite words.

## Technologies used
- HTML
- CSS
- JAVASCRIPT
- GITHUB

## API
Wordly uses the Free Dictionary API to retrieve word definitions, pronunciation, examples, and other available information.

## How to Run
- Clone/ Download the repository
- Open the project in VSCode
- Open index.html in a browser using live server.
- Enter a word and click search
- An internet connection is required to retrieve information and data from the dictionary.
## Project Structure
- Index.html - page structure
- style.css - page styling
- script.js - search functionality and API results
- readme- documenting the project
- gitignore- files excluded from GIT
